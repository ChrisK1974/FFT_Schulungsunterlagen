# Checkliste Softwareprüfung: ESTW L90

## Grundsatz
Bei jeder Prüfung sollten die wichtigsten Bereiche systematisch durchlaufen werden:

---

## 1. Prüfungsvoraussetzungen

- [ ] PT1 vorliegend
- [ ] PT2 vorliegend
- [ ] FB034 / Modul-Freigabe vorliegend
- [ ] List of Changes / Änderungsmitteilung vorliegend
- [ ] Systemstatus TQR approved
- [ ] JIRA-Prüfbuch angelegt

---

## 2. Sicherheitsprüfung

- [ ] Flankenschutz geprüft
- [ ] Schutzräume definiert
- [ ] Signale korrekt verknüpft
- [ ] Weichenlage konsistent
- [ ] Fahrstraße logisch überprüft

---

## 3. Bedienplatzprüfung

- [ ] Bedienoberfläche korrekt sichtbar
- [ ] Weichen- und Signalstatus lesbar
- [ ] Menüstruktur nachvollziehbar
- [ ] Zuglenkung korrekt
- [ ] Log-/Fehleranzeige verstanden

---

## 4. Dokumentationsprüfung

- [ ] Prüfprotokoll vollständig
- [ ] Fehler dokumentiert
- [ ] Screenshots / Logs ergänzt
- [ ] PT1-Referenz angegeben
- [ ] Priorität gesetzt
- [ ] JIRA-Status dokumentiert

---

## 5. Abschlussprüfung

- [ ] Fehler alle bewertet
- [ ] Entscheiden: Freigabe / Verzögerung / Rückweisung
- [ ] Abschlussdokumentation vorbereitet
- [ ] Mentor informiert

---

**Hinweis:** Diese Checkliste dient als Leitfaden für die tägliche praktische Prüfung.
