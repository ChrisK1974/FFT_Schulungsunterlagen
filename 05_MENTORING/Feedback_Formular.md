# Feedback-Formular: Mentoring

## Zweck
Dieses Formular unterstützt die strukturierte Rückmeldung zu vereinbarten Prüfaufgaben im Mentoring. Es verbindet beobachtete Arbeitsergebnisse mit konkreten Lernschritten und wird im Gespräch gemeinsam ausgefüllt.

Bewertet wird nur der tatsächlich betrachtete Aufgabenumfang. Das Formular ist ein Entwicklungsinstrument, keine Freigabe, Beauftragung oder Bescheinigung einer allgemeinen Prüf- bzw. Inbetriebnahmebefugnis.

## Bewertungskriterien
Verwenden Sie dieselbe Skala wie im Selbstreflexions-Checkpoint. Wählen Sie je Bereich einen Wert und begründen Sie ihn mit einem beobachteten Beispiel.

| Wert | Beschreibung |
|------|--------------|
| 1 | Grundlagen noch nicht sicher; eng geführte Anleitung erforderlich |
| 2 | Teilverständnis vorhanden; häufige Unterstützung erforderlich |
| 3 | Definierte Aufgaben unter Anleitung nachvollziehbar bearbeitet |
| 4 | Vereinbarte Aufgaben weitgehend selbstständig und nachvollziehbar bearbeitet; Grenzen erkannt |
| 5 | Vereinbarte Aufgaben wiederholt sicher bearbeitet, begründet und im Review bestätigt |
| n. b. | Noch nicht beobachtet bzw. praktisch erprobt |

| Bereich | Beobachtungsmaßstab | Wert | Beispiel / Nachweis |
|---------|--------------------|------|--------------------|
| Fachliches Grundverständnis | Anforderungen, Projektierung und Systemreaktion richtig zugeordnet | | |
| Verständnis Sicherungsebene | Schutzabhängigkeiten aus Planunterlagen begründet | | |
| Umgang mit Bedienoberfläche | Voraussetzungen, Bedienhandlung und Rückmeldung unterschieden | | |
| Qualität der Fehlerbeschreibung | Soll/Ist, Reproduktion, Belege und Hypothesen klar getrennt | | |
| Qualität der Dokumentation | Stände, Quellen, Ergebnisse und offene Punkte nachvollziehbar | | |
| Selbstständigkeit | Vereinbarten Umfang eingehalten, Grenzen erkannt und Unterstützung rechtzeitig eingeholt | | |

Ein Mittelwert ist nicht vorgesehen: Ein hoher Wert in einem Bereich gleicht ein offenes sicherheitsrelevantes Lernziel nicht aus. „n. b.“ ist keine negative Bewertung, sondern kennzeichnet fehlende Beobachtungsgrundlage.
